## About

I'm a full-stack engineer with a frontend focus. I build React and TypeScript microfrontend apps, the build and test infrastructure underneath them, and AI tooling that helps engineering teams move faster.

I treat **the frontend as a systems problem**: architecture, build performance, and API surface design decide what the experience is allowed to be.

## What I Work On

- Microfrontend architecture with React, TypeScript, and Module Federation
- Monorepo tooling, build performance, and test infrastructure
- API platforms and developer-facing tools
- Backend services and distributed systems in Go
- AI agents and developer workflow automation in Rust
